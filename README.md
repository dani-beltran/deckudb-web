# DeckuDB

DeckuDB is a full-stack Nuxt application for finding community-reported Steam Deck settings and performance guidance. The Vue frontend and the former `deckudb-api` Express backend now run from one project and one origin.

## Stack

- Nuxt 4 and Vue 3
- Nitro with the migrated Express API mounted at `/api`
- MongoDB
- Steam, Claude, and Firecrawl integrations

## Routes

- `/` — home and popular games
- `/search?q=...` — Steam game search
- `/game/:gameId` — reports and settings for a game
- `/api/health` — API health check
- `/api/games/*`, `/api/steam/*`, `/api/jobs/*` — backend API

## Local development

Requirements:

- Node.js 20 or newer
- npm 11.10 or newer
- MongoDB

Copy the environment template and provide real values:

```bash
cp .env.example .env
npm install
npm run dev
```

The complete application runs at `http://localhost:3000`; a separate API process is no longer needed.

## Validation and production

```bash
npm run typecheck
npm run build
npm run preview
```

The production entry point generated by Nuxt is `.output/server/index.mjs`.

## Backend source

The migrated backend lives under `server/backend`. `server/middleware/api.ts` lazily connects to MongoDB, creates indexes once per server process, and hands `/api` requests to the Express application.

Background job code was migrated with the API, but workers remain separate long-running processes and are not started by the Nuxt web server.

## Data sources

Reports are aggregated from community forums, Steam Community, ProtonDB, ShareDeck, YouTube, and related media sources.

Community recommendations may not suit every system configuration; use them at your own discretion.
